# 村庄支线（4 条）

每条支线 = 一个新的小村庄地图（数据层新增 `MAPS["…"]`）+ 野外图加 1~2 个传送格 + 村内 NPC 与支线流程。
全部不碰引擎；战斗编组、个别新敌人都是 data/enemies.js 的数据新增（已给出定义，照抄即可）。
每条独立，删任意一条不影响其他。

---

## 支线 1 · 流民聚落「流民智慧」（ch00/ch01）

**挂载**：`ch00_field` 东南角空地加传送格 → 新地图 `ch00_liumin`（12×8 小村：几座窝棚 B、一口井、满地草席）。
**建议出现时机**：序章接讨伐任务后即可进（无前置），与黄巾之乱的时代背景贴合。

**村内 NPC**：

- 流民头领（支线发布）
- 流民老婆婆（氛围 + 一句指路）
- 流民孩童（氛围，彩蛋式吐槽）

**支线流程**：

1. 头领：村里粮袋被山贼抢进西北山洞深处（复用 `ch00_cave` 深处加一个条件触发器，`if:{flag:"sq1",is:"accept"}`）。
2. 玩家进洞触发战斗 `sq1_bandit`（编组见下），胜利得回粮袋（`set:{sq1:"bag"}`）。
3. 回村交还 → 头领酬谢 + 一段"流民智慧"台词，支线完成。

## 支线 2 · 客商村「商人被劫」（ch02）

**挂载**：`ch02_field_south` 路边加传送格 → 新地图 `ch02_keshang`（客商聚居的坞堡式小村：货车、帐篷、一间茶棚）。
**建议出现时机**：q2 开始后。

**村内 NPC**：行商东家（发布）、伙计（氛围）、茶棚老板娘（氛围+小幽默）。

**支线流程**：

1. 东家：商队两车货被"卧牛山"方向的匪徒劫走（复用 `ch02_cave2` 加条件触发器）。
2. 战斗 `sq2_bandit` 得回货箱。
3. 回村交还 → 酬金 + 玉佩；老板娘追加一句"以后茶钱给你算半价"（纯台词幽默，不做折扣系统）。

**新增数据（enemies.js）**：

```js
sq2_bandit: { enemies: ["黄巾残党", "新野匪徒", "黄巾残党"], boss: false,
              pre: "ch02.sq2Pre" },
```
（注：新野匪徒 lv25 对 ch02 偏高，若觉得难，换成 `["黄巾残党","黄巾残党","黄巾残党"]`。）

## 支线 3 · 病村「瘟疫横行」（ch03 · 许都郊）

**挂载**：`ch03_field` 边缘加传送格 → 新地图 `ch03_bingcun`（家家闭户的小村，气氛压抑；村口一口大药炉）。
**建议出现时机**：q3 期间。与 03 号文档的「华佗授五禽戏」成长桥段同村，联动最佳（也可独立）。

**村内 NPC**：老医吴普（华佗弟子，发布）、病妇（氛围）、小儿（氛围）。

**支线流程**：

1. 老医：村里时疫，缺药材——请玩家交付 **5 株草药**（野外宝箱/商店可得，收集型目标，不强制战斗）。
2. 交付 5 株草药。注意：现有 DSL 没有"扣道具/按持有数分支"的能力，实现时两案——(A) 引擎加一条 `takeItem` + 持有数条件（约 10 行）；(B) 改成无消耗的"寻药点"：村外设 3 处调查触发器，各得 1 株"艾蒿"（新物品，纯剧情），集齐 3 株回村交付。
3. 疫情得控，老医酬谢。

**text.js（ch03 下）**：

```js
sq3Ask: ["老医：几位面生，是外乡人吧。村里正闹时疫，莫靠太近。",
         "老医：老朽吴普，家师华佗。如今家师随曹公军中，",
         "老医：村里缺一味主药——就是最寻常的草药，偏偏家家都耗尽了。",
         "老医：若能凑齐五株草药，老朽便能再支起大药炉。拜托了。"],
sq3Wait: ["老医：草药五株，野外常能采到，城里杂货铺也有售。"],
sq3Done: ["（五株草药投入药炉，苦香四溢。）",
          "老医：好！有这几味药，时疫不出十日可平。",
          "老医：家师常说：'医者，医一人易，医一村难。'",
          "老医：今日医这一村的，是几位军爷。这两枚还魂丹，万望收下。"],
sq3After: ["老医：村里病气已散了大半。军爷保重。"],
sq3Woman: ["病妇：（咳嗽）官府不来管我们……倒是军爷肯来。"],
sq3Kid: ["小儿：我长大要拜吴大夫为师，学医救人！"],
```

**奖励**：`{give:["还魂丹",2]}`；flag：`sq3: accept → done`。
**设计意图**：收集型支线换换节奏；吴普/华佗的师徒线埋 03 号文档的成长桥段。

## 支线 4 · 卧龙村「耕读传家」（ch06 · 新野野外）
