# 贵人成长桥段（6 条）

角色在特定剧情节点遇贵人/谋士，一席话终身受用 → **永久属性成长**。
属性字段对齐 data/heroes.js：`atk 攻` / `int 智` / `def 防` / `spd 速` / `luck 运` / `hp 上限`。

**奖励实现两案（每个桥段都标注）**：

- **A 案（推荐，叙事最顺）**：引擎 `runActions` 加一条小动作（约 5 行）——
  `else if (a.statUp) { const h = S.party.concat(S.bench).find(x => x.name === a.statUp[0]); if (h) { h[a.statUp[1]] += a.statUp[2]; } toast(a.statUp[0] + " 属性提升！"); next(); }`
  调用：`{statUp:["刘备","int",2]}`。只此一处引擎改动，不破"新章节只加数据"的铁律。
- **B 案（零引擎改动）**：改为赠饰品（玉佩 智+3 / 护心镜 防+3 / 旧草鞋 运+1 等），台词相应改成"赠物"。每条都给了 B 案台词变体提示。

每条独立，flag 命名 `mt1`~`mt6`。

## 桥段 1 · 刘备问学郑玄（ch03 · 许都）

**出处**：《三国志》刘备师事卢植，与郑玄有旧；借许都闲居补一段"皇叔不忘问学"。
**触发**：`ch03_xudu` 加 NPC「郑玄」（大儒寓所），q3 煮酒之后、离许之前可访，一次性。

```js
mt1Meet: ["（寓所之内，一位白发大儒正执卷而读。）",
          "郑玄：是玄德啊。卢子干门下，如今就数你最叫老夫挂心。",
          "刘备：乱世飘零，学问都荒疏了，愧对师门。",
          "郑玄：呵呵。读书不为章句——老夫只问你一句：",
          "郑玄：曹操问你谁是英雄，你答上了么？"],
mt1Talk: ["刘备：……险些答不上来。",
          "郑玄：答不上，才是好事。锋芒太露，如锥处囊中，其末立见。",
          "郑玄：治学如治军——厚积薄发，藏器于身，待时而动。",
          "郑玄：回去把《孙子》再读十遍。你能活着出许都，再来谢老夫。"],
mt1After: ["（郑玄已闭门谢客。'藏器于身，待时而动'，刘备默记于心。）"],
```

**奖励**：A 案 `{statUp:["刘备","int",2]}`；B 案 `{giveEquip:"玉佩"}`（台词末句改"这枚玉佩，是卢子干当年赠老夫的——转赠你。"）。
flag：`mt1: done`。

## 桥段 2 · 普净点化关羽（ch05 · 镇国寺）

**出处**：演义第二十七回，镇国寺僧普净以手帕戒刀暗示关羽识破卞喜埋伏——本游戏卞喜战已有，此桥段为其延伸。
**触发**：`ch05_sishui`（汜水/镇国寺所在图）战后 NPC「普净」，q5 过汜水后一次性。

```js
mt2Meet: ["（镇国寺偏殿，老僧普净煮茶相候，如候故人。）",
          "普净：将军过此关，刀上又添新血。",
          "关羽：护嫂寻兄，不得不尔。",
          "普净：老僧不劝将军放下刀。只赠将军八个字——",
          "普净：'刀快不如心明，心明不如知止。'"],
mt2Talk: ["关羽：（按刀良久）……知止。",
          "普净：将军此去，尚有数关。杀伐越重，越要记得为何提刀。",
          "普净：他年若有用不尽的神力，但愿将军还记得今日这盏茶。",
          "关羽：（深深一揖）关某，记下了。"],
mt2After: ["（偏殿茶香犹在，老僧已不知去向。）"],
```

**奖励**：A 案 `{statUp:["关羽","int",1]}` `{statUp:["关羽","luck",1]}`；B 案 `{giveEquip:"护心镜"}`（台词改"这面护心镜随老僧多年，赠将军挡一支暗箭。"）。
flag：`mt2: done`。
**注**：与日后华容道"义释"遥相呼应——"知止"二字是伏笔。

## 桥段 3 · 黄承彦授阵图（ch06 · 隆中）

**出处**：演义，黄承彦为诸葛亮岳父，通晓阵法（后于鱼腹浦指陆逊出八阵图）。
**触发**：`ch06_longzhong`，q6 三顾完成之后、出山之前可访 NPC「黄承彦」，一次性。

```js
mt3Meet: ["（草庐后山，一老者骑驴而来，口中吟着《梁父吟》。）",
          "黄承彦：孔明这就出山了？老夫来迟一步，没赶上送女婿。",
          "黄承彦：罢了——诸位既是他选的主公与兄弟，",
          "黄承彦：老夫便替他，把没讲完的一课补上。"],
mt3Talk: ["（老者以枝为笔，就地画出一座阵图：八门开阖，生克相继。）",
          "黄承彦：阵者，非困人之术，是惜命之术。",
          "黄承彦：八门之中，伤杜死惊皆可用，惟'生门'要永远留给自家人。",
          "黄承彦：孔明天资胜我十倍，唯独心太急、事必躬亲……",
          "黄承彦：诸位，替老夫看着他些。莫让他把自己也填进阵眼里。"],
mt3After: ["（山风拂过，地上阵图犹存。诸葛亮独立良久，深深一揖。）"],
```

**奖励**：A 案 `{statUp:["诸葛亮","int",3]}`；B 案 `{give:"石阵书"}`（台词改"这册《石阵书》，是老夫的手稿。"）。
flag：`mt3: done`。
**注**：台词"莫让他把自己填进阵眼里"暗伏五丈原，终章玩家会回想起来。

## 桥段 4 · 童渊试枪（ch05 · 卧牛山）

**出处**：民间评话，赵云师承枪法宗师童渊（正史无，标注为民间传说即可）。
**触发**：`ch05_woniu` 赵云入队后，山道旁 NPC「白髯老翁」，一次性。

```js
mt4Meet: ["（山道旁，一白髯老翁抱枪而坐，枪身乌沉，不见锋刃。）",
          "童渊：常山赵云？站住。",
          "赵云：（一怔）……师、师父？！",
          "童渊：出山三年，让为师看看，你的'百鸟朝凰'荒废了没有。"],
mt4Talk: ["（一老一少，两枪相交，三合而止。）",
          "童渊：枪快了，心也野了。第七式'凤点头'，你抢了两分。",
          "赵云：弟子知错。",
          "童渊：记住——枪出七分，留三分给自己退路。",
          "童渊：你要护的人太多，容不得你只进不退。去吧。"],
mt4After: ["（山道空空，只余枪风扫过的痕迹。赵云收枪，若有所悟。）"],
```

**奖励**：A 案 `{statUp:["赵云","atk",2]}`；B 案 `{giveEquip:"铁枪"}`（台词改"这杆铁枪陪了为师二十年，赠你。"）。
flag：`mt4: done`。
**注**："留三分退路"呼应长坂坡七进七出（ch07）。

## 桥段 5 · 张飞义释严颜 · 粗中有细（ch10 · 巴郡）

**出处**：《三国志·张飞传》/演义，张飞生擒严颜，亲释其缚、引为上宾——"飞义释严颜"是莽撞人一生的高光。
**触发**：ch10 入蜀线（建议挂在 `luo1` 雒城战前的巴郡触发器），一次性。

```js
mt5Pre: ["（巴郡城破，老将严颜被缚至帐前，昂首不跪。）",
         "严颜：蜀中只有断头将军，没有投降将军！",
         "众将：放肆！"],
mt5Talk: ["（张飞环眼一瞪——却忽然哈哈大笑。）",
          "张飞：好硬的脖子！俺老张就稀罕你这样的！",
          "（张飞亲解其缚，扶严颜上座，纳头便拜。）",
          "张飞：老将军，俺是个粗人，方才多有得罪！",
          "严颜：（愕然良久，长叹）……败军之将，何劳张将军如此。",
          "严颜：罢！严颜这条老命，交予使君了！"],
mt5Talk2: ["刘备：（惊喜）三弟今日，何以如此精细？",
           "张飞：（挠头）嘿嘿，跟哥哥和军师学的——",
           "张飞：对人要敬，对将要诚。光靠嗓门大，收不了人心！",
           "（帐中皆笑。诸葛亮摇扇点头：翼德，长进了。）"],
mt5After: ["（巴郡平定。'义释严颜'四字，随军传开。）"],
```

**奖励**：A 案 `{statUp:["张飞","int",2]}`；B 案 `{giveEquip:"玉佩"}`（台词改"严颜解下贴身玉佩：'老夫无以为赠。'"）。
flag：`mt5: done`。
**注**：这是用户点名的"粗中有细"桥段，台词量稍多于其他彩蛋，值得。

## 桥段 6 · 华佗授五禽戏（ch03 · 病村）

**出处**：《三国志·华佗传》华佗创五禽戏授吴普，"普施行之，年九十余"。
**触发**：与支线 3「瘟疫横行」同村（`ch03_bingcun`），支线完成后解锁 NPC「华佗」限时到访（`if:{flag:"sq3",is:"done"}`，且 q3 未结束），一次性。若不做支线 3，此桥段独立挂在许都郊外亦可。

```js
mt6Meet: ["（村口来了一位负笈游医，村民奔走相告：华神医回来了！）",
          "华佗：时疫已平？吴普这孩子，没坠了我的名头。",
          "华佗：诸位军爷身上杀气重、伤病多——",
          "华佗：老朽教你们一套'五禽戏'，活血通络，健体强身。"],
mt6Talk: ["（华佗当场作势：虎举、鹿抵、熊晃、猿摘、鸟伸。）",
          "华佗：人体欲得劳动，但不当使极耳。动摇则谷气得消，血脉流通。",
          "张飞：（跟着比划，同手同脚）这、这比打仗还难！",
          "华佗：（大笑）粗汉子也有粗汉子的练法。常练之，病不得生。"],
mt6After: ["（众人依样习练，只觉气血通畅，周身暖热。）"],
```

**奖励**：A 案 `{statUp:["刘备","hp",10]}` `{statUp:["关羽","hp",10]}` `{statUp:["张飞","hp",10]}`（全员 HP 上限小增）；B 案 `{give:["仙草露",2]}`（台词改"这两瓶药膏，行军带着。"）。
flag：`mt6: done`。
**注**：五禽戏段落是全篇难得的轻松时刻，张飞同手同脚是笑点后记。
