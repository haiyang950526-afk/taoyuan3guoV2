# 渡魂记 · 超长隐藏支线（05）

**性质**：贯穿 ch00~ch11 的情感型隐藏支线。四件遗物（木牌→残信→竹简→白莲），拼出"一个无名姑娘替四个迷路的人走完了来路"。终点：洛阳废墟·白莲花海。
**本篇是在用户原案基础上做过三处手术的定稿**：

1. **郑玄线与 03 桥段 1 互锁**：ch03 刘备问学活着的郑玄（郑玄卒于建安五年，ch03 之后、ch06 之前），ch06 南阳学堂遇其弟子——先见其人，再拾其遗物。
2. **花海老头坐实为"张姓炊饼翁"**（木牌伏笔"姓张的，你徒弟走完了"的回收），左慈只留在彩蛋 4，不与渡魂记混用。
3. **洛阳花海改为终章结局前开放**（诸葛亮托包裹后、最终决战前），不做"通关后自由漫游"——省掉结局流程改动，"先安葬、再决战"情感更顺。

**判断机制（与 04 名品篇同一套）**：所有遗物在获得时 `set` 一个 `relic_*` flag，**"得过即算"**，此后一切检测只看 flag、不看背包——遗物被卖、被存、被剧情收走都不影响支线和未来收集功能。
**因此引擎改动几乎为零**：检测全是现成 flag 条件；闪回全部用文本（对齐现有"（……）"舞台提示家风，不做 CG）；花海是纯数据新地图。唯一留白：白莲之种的效果（见末节，**效果留空，由游戏设计 agent 另行设计**）。

## 三、引擎需求汇总（比原案大幅缩水）

| 需求 | 状态 |
|------|------|
| 遗物检测（背包条件） | **不需要**——全部 flag 制 |
| 闪回 CG/特效 | **不需要**——纯文本舞台提示，对齐家风 |
| 新地图（明镜观内/破败学堂/洛阳花海） | 纯数据，同桃花源做法 |
| 黄纸符 5% 掉落 | 纯数据（现有 drops 机制） |

| **白莲之种效果** | **留白**——物品已定义（饰品位、nosell、relic），效果由游戏设计 agent 定，定稿后在 desc 里补一句 |
